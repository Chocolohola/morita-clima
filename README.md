# Morita Clima

Su meteorología con Morita: el clima de La Serena, Coquimbo, Santiago, Linares, Carriel Sur (Talcahuano), Delft y Rijswijk, en español, como app instalable (PWA).

**Un solo enlace para celular y computador:** la página se adapta sola al tamaño de la pantalla.

**Instalar en el celular:** abre la dirección de esta página en el celular y elige «Añadir a pantalla de inicio» (en iPhone, desde Safari: Compartir → «Añadir a pantalla de inicio»).

Datos de [Open-Meteo](https://open-meteo.com) (modelo, no estación).
